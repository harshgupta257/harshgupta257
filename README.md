## 🚀 Featured Projects

### 🔍 [Smart Resume Analyzer](https://github.com/harshgupta257/smart-resume-analyzer) · [Live Demo ↗](https://harshgupta257.github.io/smart-resume-analyzer/)

> AI-powered full-stack web app that scores a resume against a job description using NLP.

- **FastAPI** backend with `/analyze` endpoint; **pdfplumber** for PDF extraction
- Custom **NLTK** pipeline (n-grams + stopword filtering) against a **200+ skill** dictionary
- **Weighted scoring**: 70% Jaccard skill similarity + 30% keyword overlap with actionable suggestions
- Premium dark-theme frontend with **animated SVG score rings** and drag-and-drop uploader
- Deployed on **GitHub Pages + Render**

`FastAPI` `Python` `pdfplumber` `NLTK` `Vanilla JS`
